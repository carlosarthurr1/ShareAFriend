The open format

When someone adds your site to their widget, they can point to your JSON file. The widget can then fetch your friends too, creating a discoverable web of connections — no central server needed.

  • name — your site's name
  • url — your site's URL
  • friends[] — list of sites you endorse
  • friends[].feed — link to their JSON (enables discovery)
{ "name": "My Website", "url": "https://mysite.com", "friends": [ { "name": "Alice's Blog", "url": "https://alice.blog", "desc": "Thoughts on design", "feed": "https://alice.blog/shareafriend.json" }, { "name": "Bob's Notes", "url": "https://bob.dev", "desc": "Code and coffee" } ] }

Advanced usage

Load links from a hosted JSON file and enable friend discovery.

<div id="shareafriend"></div> <script src="shareafriend.js"></script> <script> ShareAFriend.init({ el: '#shareafriend', title: 'Blogroll', theme: 'auto', jsonUrl: '/shareafriend.json', // load from file discover: true // show friends-of-friends }); </script>
