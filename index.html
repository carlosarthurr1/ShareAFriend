The open format

When someone adds your site to their widget, they can point to your JSON file. The widget can then fetch your friends too, creating a discoverable web of connections — no central server needed.

  • name — your site's name
  • url — your site's URL
  • friends[] — list of sites you endorse
  • friends[].feed — link to their JSON (enables discovery)
{ "name": "My Website", "url": "https://mysite.com", "friends": [ { "name": "Alice's Blog", "url": "https://alice.blog", "desc": "Thoughts on design", "feed": "https://alice.blog/shareafriend.json" }, { "name": "Bob's Notes", "url": "https://bob.dev", "desc": "Code and coffee" } ] }

Built for link building

ShareAFriend isn't just a widget — it's real, crawlable, semantic backlinks.

✓

Real <a> tags

No iframes, no JS redirects, no tracking wrappers. Search engines see the actual URLs.

✓

Followed by default

No nofollow. Link juice flows to the sites you endorse, just like a classic blogroll.

✓

Referer preserved

We drop noreferrer so your friends' analytics see you as the referring source.

✓

XFN microformats

Mark relationships with rel="friend", met, colleague… Same format the old blogosphere used.

✓

h-card ready

Each link is an h-card. IndieWeb parsers and Webmention tools can read your blogroll as structured data.

✓

No-JS fallback

Put static <a> tags inside the container — JS enhances them. Crawlers see real links even without executing JS.

Advanced usage

Load links from a hosted JSON file and enable friend discovery.

<div id="shareafriend"></div> <script src="shareafriend.js"></script> <script> ShareAFriend.init({ el: '#shareafriend', title: 'Blogroll', theme: 'auto', jsonUrl: '/shareafriend.json', // load from file discover: true // show friends-of-friends }); </script>

For maximum SEO, use the progressive-enhancement pattern — real links in the HTML, enhanced by JS:

<div id="shareafriend"> <h3>Friends</h3> <ul> <li><a href="https://alice.blog" rel="friend met">Alice's Blog</a></li> <li><a href="https://bob.dev" rel="colleague">Bob's Notes</a></li> </ul> </div> <script src="shareafriend.js"></script> <script>ShareAFriend.init({ el: '#shareafriend' });</script>
